User Management

Create several users at once (Excel/CSV)
Download the template, fill in one row per user — no limit on numbers (100, 200... it goes through in a single import), the password may be left blank (auto-generated, downloadable after creation) — then upload the completed file below. Each row is checked before creation: invalid rows are flagged and not created.

Online Registration

Applications submitted by candidates from the public portal registration.html. On approval, the student account is created automatically (login email, temporary password and student ID generated), and the candidate finds their credentials by tracking their application.

Registration Period

Outside this period, the public form shows a rejection message and no longer accepts new applications. Leave a date blank to set no bound on that side (e.g. leave the end date blank for registration open until further notice).

Course Unit Management

Create a course unit for a given level, then assign it to one of your lecturers (from the same department). The lecturer will then find this course unit in their own space.

Quick import from a file
Upload a PDF or Word (.docx) file containing the list of course units (one course-unit name per line): they will be proposed for creation all at once, for the department and level chosen below.

Marks Export (Excel)

Choose a class (department + level): the file will contain one row per student (student ID, last name, first name) and one column per assignment/course unit with the corresponding mark.

List of Enrolled Students (Excel)

Download the nominal list of enrolled students (student ID, last name, first name, contacts, biodata...), with a summary sheet of headcounts. Leave "All Departments" and/or "All Levels" to not filter on that criterion.
