User Management

Create several users at once (Excel/CSV)
Download the template and fill in one row per user — no limit on the number (100, 200... in a single import). The password may be left empty (generated automatically and downloadable after creation) — then upload the completed file below. Each row is checked before creation: invalid rows are flagged and not created.

Course Management

Create a course for a given level, then assign it to one of your lecturers (of the same department). The lecturer will then find this course in their portal.

Courses are grouped by module with credit hours, and attached to a semester (Sem 1 to Sem 10) in addition to the level. A course is passed with a score of 50/100 or more.

Quick import from a file
Upload a PDF or Word (.docx) file containing the list of courses (one course name per line): they will be offered for creation all at once, for the department, level, module and semester chosen below (all courses in the file share the same module/semester; each one can then be edited individually from the list above).

Scores export (Excel)

Choose a class (department + level): the file will contain one row per student (index number, last name, first name) and one column per assignment/course with the corresponding score.

List of registered students (Excel)
